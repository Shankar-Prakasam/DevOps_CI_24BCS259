
# Restaurant Ordering and Billing System

## Project Description
A Java application that calculates restaurant bills based on food item prices and quantities.

## Features
- Add food items
- Calculate subtotal
- Calculate 5% GST
- Calculate final bill
- Validate item quantities

## Technologies
- Java 21
- Maven
- JUnit 5
- Git and GitHub
- Jenkins

## Build and Test
Run the following command:

mvn clean test

## Version Control
This project uses Git and GitHub for version control.
Changes are tracked through commits and branches.

Billing Update

The billing module calculates the subtotal, applies 5% GST, and calculates the final bill amount. It also validates item prices and quantities to prevent invalid entries.
