
# Restaurant Ordering and Billing System

## Project Description
A Java application that calculates restaurant bills based on food item prices and quantities.

## Features
- Add food items
- Calculate subtotal
- Calculate 5% GST
- Calculate final bill
- Validate item quantities

## Technologies
- Java 21
- Maven
- JUnit 5
- Git and GitHub
- Jenkins

## Build and Test
Run the following command:

mvn clean test
